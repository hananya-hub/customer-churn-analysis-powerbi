# 📊 Customer Churn Analysis – Power BI

This project uses **Power BI Desktop** and **Excel** to analyze customer churn,
identify at-risk customers, and support data-driven retention strategies.
The dashboards focus on customer behavior, churn risk segmentation, and
business-oriented insights.

---

## 🎯 Project Objective

The objective of this project is to help businesses **reduce customer churn**
by identifying patterns and risk indicators early, enabling proactive customer
retention actions.

---

## 🛠️ Tools Used

- **Power BI Desktop**
  - Interactive dashboards
  - DAX-based measures
  - Customer risk and segmentation analysis
- **Microsoft Excel**
  - Dataset storage and preprocessing

---

## ✨ Key Features

📌 **Churn Risk Identification**  
Identify customers who are more likely to churn based on behavior and attributes.

📌 **Customer Segmentation**  
Group customers by shared characteristics and churn risk for targeted engagement.

📌 **Interactive Dashboards**  
Dynamic visuals for exploring churn drivers and customer risk profiles.

📌 **Business-Focused Insights**  
Dashboards designed to support decision-making, not just visualization.
